01 — Sistema

Inteligencia que lo
impregna todo

AETHER es un sistema de inteligencia de riesgos globales que corre completamente en local, sin servidor, sin base de datos, sin dependencias de backend. Un único archivo HTML con todo el motor analítico embebido — e instalable como PWA en cualquier dispositivo móvil con soporte offline completo.

El algoritmo de cinco capas combina scores base calibrados con 15+ organismos internacionales, vectores de velocidad por categoría, una matriz de correlación 16×16, propagación de shocks en cascada con lag y decaimiento configurables, y 400 simulaciones Monte Carlo que generan bandas de confianza p10/p50/p90. Cada shock se propaga generando impactos de segundo y tercer orden. El Shock Simulator permite introducir perturbaciones manuales o usar 8 escenarios predefinidos — Pandemia, Recesión Global, Guerra Regional, Colapso Climático y más.

La visualización es dual: mapa coroplético clásico D3.js y globo 3D interactivo Three.js con 92 arcos geopolíticos en 5 tipos — alianzas, tensiones, flujos comerciales, rutas energéticas y migraciones masivas. Completamente responsivo con soporte táctil, con puente en tiempo real entre ambas vistas. Las Señales de Alerta monitorizan 64 fuentes oficiales — OMS, FAO, ACLED, GDELT, SIPRI, NOAA, IMF — ponderadas dinámicamente por el score activo de cada categoría.

La IA no es un chatbot genérico. Es Mistral corriendo en tu máquina, con contexto completo de la región activa, generando predicciones estructuradas, escenarios Optimista/Base/Pesimista y análisis sin enviar datos a ningún servidor externo. Once módulos interactivos, 201 países, 16 dimensiones de riesgo.

02 — Algoritmo

Motor de
cinco capas

01
Score Base
Datos históricos calibrados con World Bank, Freedom House, Fragile States Index, GHS Index y 15+ organismos internacionales. Actualizable en tiempo real vía World Bank API.
score_base = f(HDI, FSI, Freedom, SIPRI, GHS, WB_indicators)
02
Vector de Velocidad
Cada categoría por país tiene un vector de tendencia — no solo el estado actual sino la dirección y magnitud del cambio. Un país con score 45 subiendo a +0.8/semana es más peligroso que uno con 65 estable.
score_vel = base + (base × velocity × 0.28)
03
Boost de Correlación
Matriz de correlación 16×16. Cuando categorías fuertemente correladas están simultáneamente en zona de riesgo, el score se amplifica. Economía + Finanzas elevadas = más peligroso que cada una por separado.
score += Σ(CORR[i][j] × score_j × weight) if score_j > threshold
04
Propagación en Cascada
Cada par de categorías tiene {strength, lag (semanas), decay}. Un shock climático tarda 4 semanas en impactar la seguridad alimentaria con 80% de intensidad, atenuándose 5%/semana. La cascada genera impactos de segundo y tercer orden.
shock[t+lag] = magnitude × strength × (1 − resilience×0.4) × (1−decay)^t
05
Monte Carlo & Resiliencia
400 simulaciones con ruido gaussiano (Box-Muller) generan bandas de confianza p10/p25/p50/p75/p90. El Resilience Index modela la capacidad de amortiguación — países con alta ciencia, buena gobernanza y diversificación energética absorben mejor los shocks.
P(score_T ∈ [p10,p90]) = 0.80  |  resilience = Σ(cat_strength_inv × weight)

05 — Instalación

Cero dependencias.
Un archivo.

01
Instalar Ollama + Mistral
IA local opcional. Si no necesitas predicciones, puedes saltar al paso 3.
ollama pull mistral
  • Ollama para Windows / macOS / Linux
  • Mistral 7B (~4GB, corre en CPU o GPU)
02
Arrancar Ollama con CORS habilitado
Necesario para que el navegador pueda conectar con el servidor local. No uses OLLAMA_ORIGINS="*" ni OLLAMA_HOST=0.0.0.0: el primero deja que cualquier web que visites hable con tu Ollama desde tu navegador, y el segundo lo expone a toda tu red local, en ambos casos sin autenticación.
# Windows PowerShell
$env:OLLAMA_ORIGINS="https://franjuanp.github.io,http://localhost:8080"; ollama serve
# Linux / macOS
OLLAMA_ORIGINS="https://franjuanp.github.io,http://localhost:8080" ollama serve
03
Servir AETHER localmente
Necesario para cargar el mapa D3.js desde CDN sin errores CORS.
cd /carpeta/con/AETHER
python -m http.server 8080
04
Abrir en el navegador
Chrome o Edge recomendado. Firefox también funciona.
http://localhost:8080/AETHER_v1.html
